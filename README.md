## 🔗 Smart Links & Secret Keys (Zero Buyer Effort)

Prices dynamically adapt depending on the smart link you share. **No buyer login or password required.**

| Audience / Buyer Type | Smart Link Format | What Buyer Sees | Security Note |
| :--- | :--- | :---: | :--- |
| **Wholesale / Super Stockists** | `https://shaktidevelops.github.io/Vellum/?k=prime` | **Wholesale Rate** | Share only with verified volume/bulk buyers |
| **Portal Sellers & Resellers** | `https://shaktidevelops.github.io/Vellum/?k=seller` | **Reseller Rate** | Share with Meesho, Amazon, Flipkart & WhatsApp resellers |
| **General / Public Browsers** | `https://shaktidevelops.github.io/Vellum/` *(Clean URL)* | **Retail MRP** | Safe public lookbook with **zero wholesale cost leakage** |

> 💡 **Tamper-Proof Protection:** If an unauthorized person edits the URL (typing `wholesale`, `cheap`, or random letters), Vellum immediately fails safe and displays **Retail MRP**.
